# 내 음악 파일 넣기 (선택)

기본 배경음악은 게임에 내장된 K-pop 스타일 오리지널 전투곡(합성)입니다.
직접 가진 음원으로 바꾸고 싶다면:

1. mp3 / m4a 파일을 이 `music/` 폴더에 넣습니다. (예: `stage.mp3`)
2. `list.json` 에 화면별 파일 이름을 적습니다.

```json
{ "title": "title.mp3", "stage": "stage.mp3", "boss": "boss.mp3" }
```

3. 다시 배포하면 해당 화면에서 그 파일이 반복 재생됩니다. 비워 두면 내장 합성곡이 나옵니다.

> ⚠️ 저작권: 시판 K-pop 음원을 GitHub Pages 같은 **공개 사이트에 올리면 저작권 침해**가 됩니다.
> 직접 만든 곡, 사용 허락을 받은 곡, 상업 이용 가능한 무료 음원만 넣으세요.

4. `service-worker.js` 의 `CACHE` 버전 숫자를 올려야 아이패드에 바뀐 목록이 반영됩니다.
